# Siddhartha Singh — Portfolio

Personal portfolio site built with React, Vite, Tailwind CSS, and Framer Motion.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Site content (experience, projects, skills, education, links) lives in `src/data/portfolio.js` — update it there to keep copy in sync across the site.
